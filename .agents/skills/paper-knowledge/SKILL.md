# paper-knowledge · 沉淀可复用理解

输入：已接受科学结果、核心机制/证据、最新正式知识快照和用户内容。输出：语义裁决后的新增/更新/拆并/不变及成组候选。术语出现一次、同名标题、引文数或运行完成不是新增/成熟度依据。

| 当前轮 | 只加载的指南 | 当前结果 |
|---|---|---|
| K1 | [candidates](references/candidates.md) | 可迁移候选、语义查重与处理建议 |
| K2 | [impact](references/impact.md) | 旧→新/不变、依赖影响与未解问题状态 |
| K3 / 确需新解释 | [explanation](references/explanation.md) | 独立机制、有效例子与适用边界 |
| K4 | [composition](references/composition.md) | 保留用户原话及旧有效内容的更新组 |

只读当前指南与必要 [更新协议](../paper/references/protocol-update.md)/[证据协议](../paper/references/protocol-claim-evidence.md)片段。无需新增解释时 K3 有理由跳过，不机械造知识。单篇任务整理可由协调者承担；多阅读者只提候选，统一在同一正式快照顺序去重/整合，不并发覆盖共同页。

迁移价值来自能独立解决问题、解释机制并判断边界；单篇专有机制标明专有条件。导航反链不是语义依赖，支持数不自动提升裁决。新证据只修改真正受影响的判断/段落，变版只触发复核。未解问题有具体位置、状态、竞争解释与后续区分依据，不默认另建公开问题卡目录。

成文才加载 [knowledge 模板](assets/knowledge.md)、[写作](../paper/references/writing.md)及 [Obsidian](../paper/references/obsidian.md)。正式知识、论文与专题互有解释价值的链接；不为链接数机械造关系。候选同组审阅，正式提交遵守 [审阅协议](../paper/references/review-publish.md)，digest 不是授权。
