# K2 · 判断增量、依赖与开放问题

本轮 E4/E5/E6。只读候选、旧判断及新固定来源，必要 [更新协议](../../paper/references/protocol-update.md)片段；索引只提供待核影响，不自动裁决语义。

1. 明确旧判断、证据及范围，新材料支持的是实例补充、条件变化、反例、证据增强/减弱还是不变。说明旧→新、依据与影响，不能以新稿较新整页替换。
2. 从显式依赖取候选，逐项核新事实是否改变其机制/前提/选择；导航链接不等于依赖。循环用已访问对象与实际变化终止；变版是需复核，不自动判错。
3. 开放问题区分未决、暂有条件解答、证据不足、已解决/重开等真实状态。解决需要回答原问题的证据，不因任务结束而关闭。新证据不足时保留竞争解释和后续观察。

交付真实判断增量或不变、每项受影响段落及处理理由、问题状态/依据、需要再核的科学任务。接受条件：修改范围与证据匹配，未把支持数变成成熟度；已有正确独特内容与用户原话有保留策略。结束交回控制，统一顺序整合。

协调写者可用 `uv run python .agents/skills/paper/scripts/research.py --root . derive impact --event <实际event-ID> --source <固定source-ID>` 取待核对象，再按具体语义裁决 `derive resolve`；`--help`/更新协议提供其字段。取影响集合不是自动完成复核，导航链接不得被当依赖传播。
