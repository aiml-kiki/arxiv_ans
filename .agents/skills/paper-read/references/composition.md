# R4 · 连贯论文候选

**输入准备：** 按 [owner 契约](../../paper/references/unit-owner.md#输入暂停与恢复)登记旧页/冻结对照/相关知识的真实快照；缺输入时 awaiting_input→补齐→preparing，本人继续。接受产物按引用使用，成文才加载下面资源。

本轮 B13，仅在 R1–R3 所需产物已接受后运行。加载 [论文模板](../assets/paper.md)、[共用写作](../../paper/references/writing.md)、[Obsidian](../../paper/references/obsidian.md)及科学草稿的接受接口/旧正式页有关段落。模板不要提前进入三遍科学轮次。

按读者主线组织：一分钟→背景→方法→证据→实现与反证→讨论→下一步。方法默认先用简明 `text` 树状图解释动机、真实结构、模块输入/操作/输出、关键子步骤及学习/运行边界，再沿图解释；图不凭摘要新增设计。纯文本围栏后的真实标题/块/PDF 链接负责点击。

用已接受的 R3 反查正文：中心结论旁就地写明与来源不同的分析推断、可行竞争解释、区分依据和仍不能回答的部分。不要在末尾集中复述前文或新建平行判断记录；若某个“反证”不改变任何结论或研究动作，删去它。

以 R3 必留映射回查 R2 细节；关键值的作用、负面结果和未知后果直接可见。主结果讲条件证据，不全表搬运。旧页独特有效内容和用户原话保留，稳定 ID 不因重排改名。

完成双向核对：来源→正文关键内容未丢，正文→来源措辞未变强，图↔正文接口/模块/训练或证明依赖一致。发现科学缺项回对应轮，不在成文猜填。交付完整 Markdown 候选、具体来源/回查结果、真实知识线索与剩余限制；作者不直接发布共同知识或正式页。

交付前按 [共用写作](../../paper/references/writing.md#交付前的展示检查)做展示核对；重点核一幅方法总览与正文真实接口一致、必留实现值及未知后果有落点。结构检查与实际界面检查分别如实记录。
