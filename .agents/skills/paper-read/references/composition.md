# R4 · 连贯论文候选

**输入准备：** 按 [owner 契约](../../paper/references/unit-owner.md#输入暂停与恢复)登记旧页/冻结对照/相关知识的真实快照；缺输入时 awaiting_input→补齐→preparing，本人继续。接受产物按引用使用，成文才加载下面资源。

本轮 B13，仅在 R1–R3 所需产物已接受后运行。加载 [论文模板](../assets/paper.md)、[共用写作](../../paper/references/writing.md)、[Obsidian](../../paper/references/obsidian.md)及科学草稿的接受接口/旧正式页有关段落。模板不要提前进入三遍科学轮次。若按 [上下文成本与证据交接](../../paper/references/context-cost.md)有净收益，可由全新上下文助手组织初稿；owner 必须裁决科学内容并承担唯一候选写入。

按读者主线组织：一屏结论与边界→背景→机制总览→模块深读→按主张核证→最小虚拟重实现→讨论。按 R1 中心问题和 R3 必留映射分配篇幅，一般模块闭合必要接口即可；背景须有已核的直接前驱/替代机制及真实改动。优先用原文实际实例贯穿，超出原例的步骤标推演。

由已接受 R2 边契约生成简明运行/推理总览，保留主路径、汇合、侧支及到局部展开的接口。默认可点击提纲；共享节点、多路汇合或反馈难以表达时用 Mermaid，图后给原生导航。复杂模块在对应正文用局部图或操作解释展开；跨模块学习/刷新影响解释时，另给短的能力形成图并指明受影响节点。**总览＋局部图＋正文**共同覆盖全部决定性边，不要求所有内部边挤进一图；共享输入、关键前处理和未知接口不得消失。无原文连线不新增箭头，正文不逐句抄图。

用已接受的 R3 反查正文：中心结论旁就地写明与来源不同的分析推断、可行竞争解释、区分依据和仍不能回答的部分。系统级替代与单模块增量分开裁决；若中间输出数量/分布或用户所见展示改变，明确残余混杂，不能写成已隔离机制贡献。不要在末尾集中复述前文或新建平行判断记录；若某个“反证”不改变任何结论或研究动作，删去它。

以 R3 必留映射回查 R2 细节；关键值的作用、负面结果和未知后果直接可见。主结果讲条件证据，不全表搬运。旧页独特有效内容和用户原话保留，稳定 ID 不因重排改名。

压缩前核两项：训练/生产的实际模型身份、共享关系和更新状态是否仍可辨；作者仅提出的可选操作是否被画成必经边。前者影响解释就保留，后者在图和正文一致标条件，不为简图加强原文。

按来源→R2 契约→全页、全页→契约→原文双向核证；owner 对全部决定性边核原页，含共享输入、侧支与汇合。R2 漏科学边回 R2，仅成稿遗漏或层次不清修 R4。交付完整候选、具体回查结果、知识线索及限制，不直接发布正式页。

交付前核：总览能快速理解整体，局部可点击展开；全部核心模块有输入/变换/输出，学习/证明与运行边界清楚；关键“？”有来源状态、后果及区分观察；数字的模型/对象/口径/条件正确。原文关键矛盾、最强同约束竞争解释及必留配置不可因压缩丢失。按 [共用写作](../../paper/references/writing.md#交付前的展示检查)核展示；结构、字数或可渲染不能代替科学接受。
