本轮 B13，仅在 R1–R3 所需产物已接受后运行。加载 [论文模板](../assets/paper.md)、[共用写作](../../paper/references/writing.md)、[Obsidian](../../paper/references/obsidian.md)及科学草稿的接受接口/旧正式页有关段落。模板不要提前进入三遍科学轮次。若按 [上下文成本与证据交接](../../paper/references/context-cost.md)有净收益，可由全新上下文助手组织初稿；owner 必须裁决科学内容并承担唯一候选写入。

按读者主线组织：一屏结论与边界→背景→可点击机制地图→模块深读→按主张核证→最小虚拟重实现→讨论。以已接受的 R2 短机制边契约生成一张运行/推理主图，不到成稿才凭记忆补边；跨模块学习、蒸馏或刷新会改变解释时，另给一张短的能力形成/状态更新图并指出受影响主图节点。地图默认用 Markdown 层级提纲，节点直接链正文；**三路以上并行、共享节点、双重打分/汇合或反馈**无法在提纲中一眼追踪时，使用 Mermaid 表达拓扑，图后另给原生可点击导航。总览只保留主路径与交接，关键局部按复杂度另展开一层。逐模块把原文公式/接口的每项关键输入（包括共享输入）映射到图中入边，关键前处理在模型节点前单列；逐边核变换、去向和原文位置。不同训练/增量/评审流程无原文连线就分开，不凭摘要新增箭头。正文不逐句复述图。

用已接受的 R3 反查正文：中心结论旁就地写明与来源不同的分析推断、可行竞争解释、区分依据和仍不能回答的部分。系统级替代与单模块增量分开裁决；若中间输出数量/分布或用户所见展示改变，明确残余混杂，不能写成已隔离机制贡献。不要在末尾集中复述前文或新建平行判断记录；若某个“反证”不改变任何结论或研究动作，删去它。

以 R3 必留映射回查 R2 细节；关键值的作用、负面结果和未知后果直接可见。主结果讲条件证据，不全表搬运。旧页独特有效内容和用户原话保留，稳定 ID 不因重排改名。

完成双向核对：来源→R2 边契约→图/正文，图/正文→边契约→原文；owner 对每条会改变运行、复现或解释的边核原页，包含侧支与汇合。正文措辞不得强于来源，图↔正文接口/模块/训练或证明依赖一致。R2 契约漏掉科学边就回 R2；仅成稿漏画已有边则修 R4，不在成文猜填。交付完整 Markdown 候选、具体来源/回查结果、真实知识线索与剩余限制；作者不直接发布共同知识或正式页。

交付前做语义验收：地图除节点外须显示真实的串行、并行汇合、侧支和反馈关系；每个核心模块可见输入、关键变换与输出/交接，学习/证明和运行边界没有混写。关键“？”在正文有来源状态、可能实现及可区分观察，地图与正文双向一致。结果数字核对模型/对象/指标/条件和物理页；原文内部会改变重实现的矛盾、最强同约束竞争解释不能在压缩时消失。再按 [共用写作](../../paper/references/writing.md#交付前的展示检查)核必留实现值、负面证据和展示。缺失科学内容回原轮，展示缺口本人修；不以图行数、标题齐全或机械检查代替接受。
