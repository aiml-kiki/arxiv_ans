# R2c · 第二遍：命题、证据和验证配方

本轮 B6/B7/B8。只加载接受机制、当前主结果/关键控制/消融/反例与 [命题证据协议](../../paper/references/protocol-claim-evidence.md)有关片段。按主命题分批读，不搬全表。

## 动作

1. 分开作者声称、直接观测和分析者解释。主命题及会改变边界的负面观察必须有真实定位。
2. 每项决定性证据讲清对象、数据/split/测量、单位/分母、对照、预算/关键配置及不确定性口径。共同协议定义一次，变更条件独立说明。
3. 选择主结果、可区分机制的消融/控制、重要负面结果；其他成绩定位原表。没误差条/多次重复等信息保持未知，不套统一显著性阈值。
4. 写可核的验证配方：数据/对象、流程、指标或证明检查、必要资源和披露缺口；说明未知会妨碍哪项复查。虚拟配方不称实际复现。

交付：核心命题与逐项条件证据、作者归因与支持范围、重要负面结果、验证配方、待区分解释及实际覆盖。核心判断按共享字段注册；一般说明自然叙述。

接受条件：数字与单位定位正确、对照和范围足以理解结论，未把消融/相关性升为因果或把分析完成升为实验复现。交回控制，由协调者决定接受/具体补证。
