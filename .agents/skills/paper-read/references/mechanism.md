# R2a · 第二遍：走通机制

本轮 B2/B3。输入为接受的 R1、当前方法/定义/接口来源及必要类型适配。只解释前向或研究构造路径，不在本轮同时裁决全部实验和写第三遍。

## 动作

1. 建立输入/输出契约：对象、单位/类型/形状、可见信息、状态/所有者、约束与来源。关键中间量和接口讲出含义，模块名不能替代操作。
   对中心主张走一个有效例子并指出改变结果的关键接口；若只把论文模块名称改写一遍，不能接受本轮。
2. 从一个有效输入逐步走到最终输出：每步读什么、做什么、输出给谁，计算/信息/状态在哪里改变。教学数值明确标推演；论文提供的实例另标来源。
3. 把决定接口或行为的已披露配置保留下来，给实际值及作用。缺失步骤明确哪个接口未闭合、妨碍什么；不猜隐层、mask 或缓存行为。
4. 在同一科学稿留下**短机制边契约**：核心模块及其输入→变换→输出，跨模块的关键边（含共享输入、并行汇合、侧支、反馈）各绑定原文页/节/图；原文没交代的边标“？”及其复现后果。只收会改变运行、解释或虚拟重实现的边，不另建公开卡片或在本轮画成稿图。按原文反查遗漏边，再按契约反查每条边的来源。

## 交付与停止

交付可接续的机制说明、短机制边契约、一个闭合路径的例子、关键配置及来源、未知后果和疑问更新。已知串行/并行/反馈按实际结构说清；此处是科学接口，不写最终图或加载成文模板。模块能力若来自提示、外部模型、检索/记忆、规则算法或人工反馈，就地记真实来源及边界；涉及学习的更新边留给 R2b 补齐。

接受条件：读者能恢复核心输入、操作、中间量和输出；决定性边能回查原文且原文的决定性路径没有漏边，形状/可见信息/状态无隐含跳步，推演与作者事实分开。若原文不足，明确受阻范围可作为有条件结果。保存核对并登记接受后，才加载下一阶段。
