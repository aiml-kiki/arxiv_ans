# paper-trace · 可追溯的研究地图

输入：焦点问题、范围/约束、种子或现有研究集合、真实可用 provider。输出：持久实际查询/选择记录、引用事实与有据技术关系、覆盖限制及 topic 候选。书目长或图好看不是覆盖充分。

| 当前轮 | 只加载的指南 | 当前产物 |
|---|---|---|
| T0 / 增量入口 | [incremental](references/incremental.md) | 改变对象、需重开的检索/判断 |
| T1 | [scope](references/scope.md) | 初始范围、纳排、预算及停止条件 |
| T2 | [search-screen](references/search-screen.md) | 实际查询/集合、去重与筛选裁决 |
| T3 / 可迭代 | [snowball](references/snowball.md) | 一轮前后向候选及筛选 |
| T4 | [lineage](references/lineage.md) | 引用事实图与双端技术谱系 |
| T5 | [coverage](references/coverage.md) | 覆盖/停止裁决、缺线和选读问题 |
| T6 / 专题成文 | [composition](references/composition.md) | 有边界的研究地图与开放问题 |

一位独立追溯 owner 按 [自主执行契约](../paper/references/unit-owner.md) 完成所选阶段与内部核对，真实集合/筛选落盘，只交最终结果或异常。只加载当前指南与必要来源/证据片段；新论文按问题深度局部阅读，确需完整精读才交独立 paper-read owner，不全文读所有候选。

引用图保留真实边，可用 SCC/投影派生视图，不能删边强造 DAG。引用不是继承；技术关系须双方方法依据。跨来源判断缺分析时借 paper-compare 的必要当前轮；T6 使用 C9 成文，不另建第七能力。

成文才加载 [topic 模板](assets/topic.md)、[写作](../paper/references/writing.md)和 [Obsidian](../paper/references/obsidian.md)。只有真正按系统调研执行时才加载 [系统综述模块](assets/modules/systematic.md)。实际集合、选择依据、关键变化持久保存；知识整理与正式提交由协调者顺序整合。
