# T0 · 增量研究入口

本轮 D8，仅有实际旧范围、集合或判断且需要增量时运行；没有这些输入具体说明不适用。读取上次有效范围、真实集合/日期、固定来源、重要判断和当前用户问题。找新工作、改版、反例或新约束改变了什么，哪些旧检索标准/判断/技术关系需要重开。

新版本不是自动否定旧证据；版本变化按具体内容及影响定位。范围变动要检查旧筛选是否仍有效，新增同方向文章不能只在旧文尾追加摘要就算综合。

交付：变化对象及依据、旧→新或尚未变化、受影响任务/段落、需重开的 T2/T3 或局部证据/比较任务、仍有效缓存。接受条件：增量定位具体，未变部分复用有理由，真正变化进入语义复核而非全量重跑。owner 核对登记后选择实际路线；跨单元冲突才交主会话。
