# T4 · 引用事实与技术谱系

本轮 D5/D6。输入为固定引用数据、双方已读方法/机制及真实来源位置。引用图和技术图分别回答“谁引用谁”和“哪些设计改变怎样发生”。

1. 事实图保留全部真实已知边，记录数据/版本及能力限制。遇环使用 SCC 或明确投影，原图不删边以满足 DAG；派生视图可重建。
2. 逐条核重要技术关系两端，注册具体对象/接口、原文位置和关系层次。原文明说的继承、双端方法确认的分析者推断、仅引文/时间线索分开。
3. 谱系解释旧约束/合理性、瓶颈条件、改变的接口、保留/替代/组合/分叉、能力与新成本。作者未说动机时不代造历史。双方理解不够则局部补读。

交付：事实图与数据限制、正文可解释路线、有据技术边、未证线索和补证问题。接受条件：每项强技术关系有双端依据，不把引用边晋升继承或把漂亮箭头当证明。结束交回控制。

事实图派生：`uv run python .agents/skills/paper/scripts/research.py --root . query graph --trace <trace> --projection all`，或按真实纳入集合选 included。技术边仍由作者按共享语义协议核定；图命令不产生科学继承关系。
