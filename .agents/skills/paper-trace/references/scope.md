# T1 · 定义可回答的研究范围

本轮 D1。明确焦点问题、任务/对象/约束、分析单位、材料类型与时间范围；区分给定材料综合、定向追溯和系统调研。题目不能超过可覆盖范围。

定义初始纳排标准、真实 provider 能力、资源/时间预算与停止条件。用 `query init/scope` 的 `--queries-budget/--pages-budget/--candidates-budget/--fulltexts-budget/--expansions-budget` 登记可执行限额；累计实际消耗，预算耗尽明确停止或更新范围及预算，不把自由文本预算当已执行限额。标准服务问题而非便利排行；已有种子是入口，不等于代表全方向。实质歧义会改变对象才向协调者提问，其余给合理初始范围。

交付：范围与初始标准、种子/查询入口、预算、停止/扩范围条件、已知缺口。接受条件：能判断某候选为何纳入/排除，覆盖声称可被具体材料约束。owner 内保存核对后继续；不凭想象填写尚未实际取得的检索集合。
