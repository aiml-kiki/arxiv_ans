# 核心命题、证据与关系契约

只在当前轮确实需要时读相应节。论文方法事实、普通解释和导航链接无需全部注册；主贡献、关键假设、重要正负结果及跨篇判断值得注册。结构化不能代替读原文、语义核验或作者视角重构。

## 身份与固定证据

- 正式 Markdown 是唯一可编辑的研究语义源，只有 `论文/`、`知识/`、`专题/` 进入派生语义索引。`.research` 工作材料与 `审阅/` 投影不进入正式索引。
- 普通段落末尾写 `空格 + ^ASCII块ID`。既有 `^claim-*` 可以保留；新增可用 `^c-*`、`^r-*`、`^q-*`、`^d-*`。同页不重复，引用后不重排或复用。段尾块 ID 是 Obsidian 原生语法，其正常预览显示不需要隐藏。
- 核心结论、决定性依据、范围与重要限制在普通正文中直接可见；登记信息用默认折叠的 `> [!note]- 判断记录`。关系、未解问题、知识更新分别用 `关系记录 / 问题记录 / 更新记录`。这些精确标题显式声明类型，不能从普通提示块或措辞猜类型。
- 登记提示块紧邻带稳定 ID 的正文段落，中间只允许空行；依据/边界的分点可放在登记块之后。段落与 ID 不移入提示块，不改变已有引用范围。字段之间用空引用行 `>` 分段，不能依靠软换行。
- 新稿使用 `> **字段**：值`；每字段一行，重复证据/依赖另列。只折叠登记元数据和依据摘要，不能把首次解释、关键数字、重要反例、未披露后果或限制只写在折叠记录里。
- 旧的普通正文 `**研究对象：** 命题 / 关系 / 未解问题 / 知识更新` 登记仍可解析，不批量重写旧页。代码示例、注释、表格、普通引用及其他 callout 不构成登记。正式研究语义仍只编辑同一份 Markdown。
- 核心命题语义实质改变时保留旧判断或修订关系，不以换 ID 消除追溯；单纯格式修辞不创造新命题。
- `来源` 是真实 source manifest 的 `source_id` 或 `paper_id`，`版本` 与 manifest 完全一致。PDF、HTML、补充材料、代码分别固定其版本/commit 和全文哈希。来源与版本若对应多个不同全文哈希，必须明确 `哈希=`，不得任意选一份。
- `位置` 写实际页/节/表图/公式/单元格或代码行/区域，不能只有“全文”。`链接` 是该固定附件的库根相对 Wiki（PDF 可加 `#page=`），或已固定网页/代码的官方 HTTPS 回查入口；链接在判断附近，表格中的链接移到表外。
- 三类状态正交：分析完成程度、证据定位/支持范围、真实独立复现。`核验=定位已核` 只声明实际定位核对，不宣布语义支持或独立复现。

## 命题字段

推荐注册单元如下。以下是语法示例，来源名、路径、页码和命题不代表本次已核验事实；正式结果必须换成实际材料。

```markdown
固定参数且历史前缀和时间语义不变时，候选无关的状态可以复用。 ^c-example-state

> [!note]- 判断记录
>
> **判断**：机制｜提出者=分析者｜裁决=有条件支持
>
> **范围**：参数快照、可见历史和状态刷新边界。
>
> **理由**：只支持固定参数及同一历史语义，不能扩展到跨训练更新。
>
> **来源**：paper-example｜版本=v1｜核验=定位已核
>
> **支持**：位置=p.8, §3.2｜链接=[[附件/paper-example/v1.pdf#page=8|状态定义]]｜说明=公式中的状态不包含候选输入。

- **依据**：状态定义不含候选输入，[[附件/paper-example/v1.pdf#page=8|回查定义]]。
- **边界**：参数更新后的复用未被验证，不能推广到跨训练更新。
- **区分观察**：固定历史与候选，仅改变参数快照后比较旧状态和重算状态。
```

语义必要项不变：类型、判断类型、范围、提出者、至少一条证据、裁决及理由。提示块标题提供类型；`判断` 一行展开为判断类型、提出者、裁决，`理由` 单列。也可在登记块内保留完整字段名。可选：`假设`、`区分观察`、多条 `依赖`。不为填字段注册普通解释。

- 判断类型：`机制 / 经验结果 / 理论 / 实现 / 跨篇选择 / 假设`，按真实验证方式选择。
- 提出者：`作者 / 分析者`。推论不能冒充作者明说；作者声称不能冒充已证明。
- 裁决：`支持 / 有条件支持 / 证据不足 / 相反证据 / 原文未知`，后接全角 `｜理由=`，具体说明支持范围、反例及尚缺什么。
- 证据语法：`支持/限制/反驳/背景｜来源=...｜版本=...｜位置=...｜核验=定位已核/未核｜链接=...｜说明=...`。只有哈希消歧必要时加 `｜哈希=<完整64位SHA-256>`。全角 `｜` 分槽，Wiki 别名仍用半角 `|`。
- 新稿写 `> **支持/限制/反驳/背景**：位置=...｜链接=...｜说明=...`；同一登记块的共同 `来源` 行提供 source ID、版本、核验及必要哈希。证据逐项可覆盖同源核验状态；不同来源/版本须独立填写来源、版本及核验，不继承其他来源的哈希。不同来源时优先直接在各条证据填写完整槽位。解析后仍保留每条完整来源、位置、支持关系和状态；不把共同来源自动扩展到其他判断。
- 依赖语法：`**依赖：** [[知识/机制名#^c-specific-condition|必要前提]]`。目标是已注册核心判断，不能只指文件或标题。并列支持不等于同时必需前提，禁止取证据最小值或均值自动裁决。
- 数字的单位、分母、协议、对照、主要负面观察及统计限制在附近正文讲清；证据字段只保留决定性入口和支持关系，不填全部实验成绩。

## 关系字段

关系描述两项已注册理解单元如何连接；普通 Wiki 默认只是导航。引用事实另由 `query` 保存，技术承继必须读双方的机制。

```markdown
方案 B 替换了方案 A 的候选进入接口，并增加状态失效后的刷新成本。 ^r-example-interface

> [!note]- 关系记录
>
> **源**：[[论文/方案A#^c-a-interface|旧接口]]
>
> **目标**：[[论文/方案B#^c-b-interface|新接口]]
>
> **关系类型**：替代
>
> **归属**：分析者推断
>
> **范围**：相同候选信息与刷新预算下的接口变化；不能据此推出性能因果优势。
>
> **支持**：来源=paper-a｜版本=v1｜位置=p.4, Eq.2｜核验=定位已核｜链接=[[附件/paper-a/v1.pdf#page=4|A接口]]｜说明=旧接口包含候选输入。
>
> **支持**：来源=paper-b｜版本=v1｜位置=p.7, §3｜核验=定位已核｜链接=[[附件/paper-b/v1.pdf#page=7|B接口]]｜说明=新接口将候选输入后移，但需单独刷新状态。

两端接口已核，[[附件/paper-a/v1.pdf#page=4|回查 A]]、[[附件/paper-b/v1.pdf#page=7|回查 B]]；这一接口替代不能证明同预算性能更高。
```

语义必要项：类型（提示块标题提供）、一个 `源`、一个 `目标`、`关系类型`、`归属`、`范围`。技术关系 `承继/替代/分叉/组合` 如已确认必须明确双端证据；两条字段也不自动证明双端语义成立。

关系类型：`导航 / 前置 / 实例 / 证据支持 / 依赖 / 限制 / 反例 / 引用 / 承继 / 替代 / 分叉 / 组合`。

归属：`作者明说 / 分析者推断 / 待核验线索`。

方向定义：`依赖` 的源依赖目标；`证据支持` 的源支持目标。只有这两类已确认关系以及命题的显式 `依赖` 参与判断影响候选传播。前置知识、实例、普通引用、导航和待核验线索不自动触发全库重写。技术关系改变可能影响比较判断，由模型核验后明确登记相应依赖。

## 派生与机械核验

```sh
uv run python .agents/skills/paper/scripts/research.py --root . derive build
uv run python .agents/skills/paper/scripts/research.py --root . derive status
uv run python .agents/skills/paper/scripts/research.py --root . derive format --input <已核稿.md> --output .research/drafts/<run>/formatted.md
```

索引位于 `.research/index/semantic.json`，绑定正式正文全文哈希和固定来源全文/manifest 哈希，可删除重建。注册字段错误、缺失固定来源、引用不到注册对象等返回定位诊断；未注册旧页只列范围，不宣布没有科学支持。派生器只编译显式字段，不从措辞或 Wiki 猜“支持/依赖”。Obsidian 修改使旧索引失效，先重建再使用。

`format` 仅将合法旧登记折叠并精简共同来源，输出到新的内部 Markdown 草稿；核对排版前后所有显式科学字段等价，不覆盖输入或正式页，不读取模型或改写解释。科学影响比较按规范化内容计算，纯排版或槽位顺序不生成认知变化；来源版本/哈希变化仍按来源协议处理。成文者仍需检查重要依据与限制在主线中可见。

机械通过只说明格式、身份、路径和哈希满足契约。协调者仍需回查实际来源，核对断章、比较口径、图像及语义支持；机器不宣布论文为真、不计算虚假的成熟度或通用显著性。
