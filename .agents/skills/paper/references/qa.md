# 当前问题的回答

只加载相关正式正文、当前问题块、必要固定来源及证据协议的有关片段。先给有条件答案，再解释关键操作、公式或理由；已有内容足够时不重跑三遍，不默认测验、评分或长报告。

1. 核对用户引用的是哪项判断、版本和当前条件。说“继续”时读取最新相关正文与有效恢复点，保留原任务；新消息通常更新约束，不自动取代目标。
2. 原文声称、已核事实、分析者推演和用户判断分开。数学给定义、形状与有效例子；例子标明教学推演。
3. 有影响结论的缺口时只补相应来源窗口，记录实际阅读覆盖。未披露说明后果；不能把猜测写成实现事实。
4. 经核验的重大更正或用户要求保存时，将真实旧→新及影响送 paper-knowledge；否则直接回答，保持普通讨论。

用户原话留在“用户原话与我的笔记”，回应另写。笔记勾选框不是执行或写入授权。主动带读时交当前遍的认识、变化与待讨论点，等待用户讨论；默认研究模式由独立 owner 在本人会话完成，不由主会话逐轮续派。
