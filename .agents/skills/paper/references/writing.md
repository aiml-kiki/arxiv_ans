# 成文：把已接受的理解讲清

仅成文/审阅轮加载本文件、目标产物的一个模板及 [Obsidian 展示](obsidian.md)。科学阅读轮不加载展示资源。模板是默认阅读顺序，删除占位符、提示及无内容的分析节；保留最小可编辑讨论入口。达到读者任务比填满栏目重要。

## 正文主线

开头给当前答案、实际范围及主要限制。按任务提供少量导航；叙述段落各讲一件事。机制从输入到输出讲通，关键符号、形状、操作及配置的作用就地解释；知识链接提供定义、实例、前置、限制、替代或证据，不能替代本页必要解释。

实验按主命题选择代表结果：主结果、决定性对照/消融、改变适用边界的负面结果直接可见。共同协议定义一次，后来改变的条件必须重新说明。对象、分母、单位、对照、预算/关键配置与统计限制随结果给出。其他扫参或重复成绩可折叠或回查原表；没有固定表数或字数配额。

只在核心科学判断处注册命题、证据、关系或问题，语义格式服从 [共享协议](protocol-claim-evidence.md)。采用“观察 → 推理 → 条件与限制”的正文论述；已有自然段/短表讲清时不再复制摘要、分点或判断卡。作者未披露项、分析者推演、实际观测分别说清。原话与分析分开，不制造用户笔记。

## 栏目职责与科学承载

| 部分 | 唯一职责 |
|---|---|
| 方法地图 | 动机、真实结构、核心模块输入→变换→交接和关键边界；不再画同信息流程图 |
| 方法正文 | 输入→操作→输出及设计原因；不逐字复述图 |
| 配置 | 实际值怎样改变行为、成本或验证；不重讲完整方法 |
| 证据 | 共同协议、决定性正负结果及支持范围；不搬全部原表 |
| 虚拟重构 | 最小可实现组织、未闭合接口、假设挑战、替代与作者辩护；不抄方法全文 |
| 知识 | 独立定义/机制、有效例子和边界；不重抄论文实验 |
| 比较/专题 | 共同问题、双端关系与技术演变、条件选择和反转；不堆两篇摘要 |

核心判断与证据解释只写正文一次。索引登记通过最小技术注释绑定正文块和可见来源入口，不能复制范围、裁决理由或证据摘要。仅在旧记录中出现的重要边界先融入正文；迁移工具必须给明确正文绑定并审阅。科学正文没有固定篇幅上限，重要负面证据不能删减。

## 内容复用与链接取舍

- 每一处出现承担不同阅读职责：摘要给有条件答案，正文解释机制和依据；表格给观测，段落解释支持范围，不重报整表。
- 虚拟重构不重复正向方法；各产物只承担上表所列的独有问题。
- 一组结果先交代共同协议，改变的条件就地说明。首次概念先解释再提供必要前提链接；同一论证内同一入口只链接一次，不在记录、表后和总结再次排列。不同论证需要原文时允许再次链接，无数量配额。
- 来源与边界放实际论证旁；不用长“相关页面”清单代替解释，也不每节自动添加下一步、判决或知识回链。原生反链和大纲承担发现与定位。
- 当前知识讲现行理解；只有影响理解的重要旧→新就地简述，完整批准历史留持久更新/提交记录。未解问题融入相关讨论：哪里未知、竞争解释、能区分的观察；不另重复一份问题记录。

## 用排版承载不同关系

- **段落承载推理**。一段围绕一个问题、操作或因果关系；对象、步骤或解释层次改变时分段。结论的前提、证据与限制留在邻近位置，不为缩短段落拆散判断。没有固定字数配额。
- **编号承载顺序**。输入到输出、训练阶段、证明依赖和复现步骤按实际顺序编号；并行条件、配置和边界用分点。每步先说做什么，再说输入/输出、关键约束及作用，不能把有依赖的流程写成无序清单。
- **短表承载共同坐标**。少列、短单元，比较同一对象或同一指标；长解释移到表外。设置/协议先定义，观测结果与支持范围分开讲；不把不同口径数字并成排名。表内别名链接使用 `\|`，详见展示规则。
- **强调承载重点**。只强调决定性结论、条件和误读风险；避免整段加粗、每项都加粗。中文标签用 `**标签**：正文`。旧登记 `**字段：** 值` 保持兼容。完整句子的句号放在强调外，或在标记后留空格。公式独立成行时使用 `$$...$$`，就近说明符号、形状、单位及作用。
- **提示块承载阅读意图**。abstract 给少量阅读入口，example 标教学例子，warning 给实质限制，question 给真实问题；note 仅折叠有独立价值的次要展开，不折叠登记卡。科学段落与稳定 ID 在提示块外；主要机制、必要配置、决定性正负证据与条件保持直接可见。不为每段套提示块，不用嵌套提示块堆层级。

## 导航与讨论

标题按真实内容命名，用 H2/H3 和原生大纲定位。少量导航以读者任务命名，目标必须存在；知识链接前先解释必要概念。讨论区分“用户原话与我的笔记”和“分析与回应”，不制造用户已掌握或已复现状态；无内容只留可替换的编辑提示。下一步写所解决的缺口及真实入口。

## 两方向回查

- 来源→正文：已接受的核心路径、学习/证明、关键配置、重要反例与未知后果有落点；旧页的独特有效解释和用户原话有保留理由。
- 正文→来源：每项强判断能回查实际版本和具体位置，措辞没有超出证据，图/公式/教学例子没有被写成作者实测。
- 地图→正文与正文→地图：论文的主要模块输入、关键变换、输出交接及学习/证明依赖互相对应；未知接口的“？”在正文解释后果，不在地图中塞整段证据。

只有措辞和格式问题在本轮修。机制断开、证据支持不足或演变因果新造，返回对应原作者科学轮次；不能在成文时猜出缺失步骤。

## 交付前的展示检查

1. 首屏能找到答案、范围和少量真实导航；章节能由大纲定位。
2. 推理分段、顺序编号、条件分点、短表比较各有用途；主要条件与负面证据未被折叠。
3. 公式、图与正文对应；链接别名表达目的，PDF 指物理页；无占位符或假可点击图中文字。
4. 重排保留旧标题入链、稳定块、用户原话及已注册判断的完整范围，技术绑定仍指向实际正文和可见证据，不复制解释。
5. 最小讨论入口可编辑，分析与用户笔记分开；下一步有目的及真实入口。机械检查与实际界面检查分别报告。

6. 没有独立判断/关系/问题/更新卡、空分析节、重复来源清单或无下游用途的审计段；重要细节、负面证据和稳定引用仍可回查。
