# 成文：把已接受的理解讲清

仅成文/审阅轮加载本文件、目标产物的一个模板及 [Obsidian 展示](obsidian.md)。科学阅读轮不加载展示资源。模板是默认阅读顺序，删除占位符、提示及无内容的分析节；保留最小可编辑讨论入口。达到读者任务比填满栏目重要。

## 正文主线

开头给当前答案、实际范围及主要限制。按任务提供少量导航；叙述段落各讲一件事。机制从输入到输出讲通，关键符号、形状、操作及配置的作用就地解释；知识链接提供定义、实例、前置、限制、替代或证据，不能替代本页必要解释。

实验按主命题选择代表结果：主结果、决定性对照/消融、改变适用边界的负面结果直接可见。共同协议定义一次，后来改变的条件必须重新说明。对象、分母、单位、对照、预算/关键配置与统计限制随结果给出。其他扫参或重复成绩可折叠或回查原表；没有固定表数或字数配额。

只在核心科学判断处注册命题、证据、关系或问题，语义格式服从 [共享协议](protocol-claim-evidence.md)。正文仍应自然解释条件与理由，字段不能替代解释。作者未披露项、分析者推演、实际观测分别说清。原话与分析分开，不制造用户笔记。

## 用排版承载不同关系

- **段落承载推理**。一段围绕一个问题、操作或因果关系；对象、步骤或解释层次改变时分段。结论的前提、证据与限制留在邻近位置，不为缩短段落拆散判断。没有固定字数配额。
- **编号承载顺序**。输入到输出、训练阶段、证明依赖和复现步骤按实际顺序编号；并行条件、配置和边界用分点。每步先说做什么，再说输入/输出、关键约束及作用，不能把有依赖的流程写成无序清单。
- **短表承载共同坐标**。少列、短单元，比较同一对象或同一指标；长解释移到表外。设置/协议先定义，观测结果与支持范围分开讲；不把不同口径数字并成排名。表内别名链接使用 `\|`，详见展示规则。
- **强调承载重点**。只强调决定性结论、条件和误读风险；避免整段加粗、每项都加粗。中文标签用 `**标签**：正文`，不写 `**标签：**正文`；后者可能让标记原样显示。完整句子的句号放在强调外，或在标记后留空格。协议要求的 `**字段：** 值` 保留空格。公式独立成行时使用 `$$...$$`，就近说明符号、形状、单位及公式在路径中的作用。
- **提示块承载阅读意图**。abstract 给少量阅读入口，example 标教学例子，warning 给实质限制，question 给真实问题；note 折叠次要展开。主要机制、必要配置、决定性正负证据与条件保持直接可见。已注册判断及其字段保持普通正文，不包装进提示块或表格。

## 四类正文的展示主线

| 产物 | 读者先看什么 | 正文怎样展开 |
|---|---|---|
| 论文 | 有条件的贡献与实际阅读范围 | 架构 → 编号运行路径 → 学习/证明 → 证据 → 虚拟重构与批判 |
| 知识 | 独立定义与适用前提 | 机制/公式 → 教学例子 → 论文用法 → 条件、反例与来源 |
| 对比 | 共同问题与最重要关系 | 同情境 → 同轴短表 → 演变/分叉 → 双端证据 → 条件选择 |
| 专题 | 焦点问题与真实覆盖 | 问题地图 → 有目的的阅读路径 → 路线关系 → 综合取舍 → 未解问题 |

标题按真实内容命名，不重复正文结论；用 H2/H3 表示章节和子问题，原生大纲承担完整目录。导航用“看方法/核对证据/补前提/写问题”等读者任务，目标必须存在。知识链接前先就地解释必要概念，再说明链接用于前置、实例、限制或证据。

讨论区固定区分“用户原话与我的笔记”和“分析与回应”。无用户内容时只留编辑提示，不造引语、心得或已掌握状态。下一步说明要解决的缺口和具体材料/位置/问题入口，不写泛化的“继续研究”。

## 两方向回查

- 来源→正文：已接受的核心路径、学习/证明、关键配置、重要反例与未知后果有落点；旧页的独特有效解释和用户原话有保留理由。
- 正文→来源：每项强判断能回查实际版本和具体位置，措辞没有超出证据，图/公式/教学例子没有被写成作者实测。
- 框架图→正文与正文→图：论文的主要模块、接口、学习或证明依赖互相对应；图只是已接受机制的总览。

只有措辞和格式问题在本轮修。机制断开、证据支持不足或演变因果新造，返回对应原作者科学轮次；不能在成文时猜出缺失步骤。

## 交付前的展示检查

1. 首屏能找到答案、范围和少量真实导航；章节能由大纲定位。
2. 推理分段、顺序编号、条件分点、短表比较各有用途；主要条件与负面证据未被折叠。
3. 公式、图与正文对应；链接别名表达目的，PDF 指物理页；无占位符或假可点击图中文字。
4. 重排保留旧标题入链、稳定块、用户原话及已注册判断的完整范围，字段仍紧邻正文。
5. 最小讨论入口可编辑，分析与用户笔记分开；下一步有目的及真实入口。机械检查与实际界面检查分别报告。
